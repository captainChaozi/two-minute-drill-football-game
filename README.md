# 2 Minute Drill

2 Minute Drill is a free browser football strategy game I built. You take over the last two minutes of real NFL games and try to manage the clock, timeouts and play calls to win it.

## How it works
- Start from a real late-game situation.
- Choose plays while the clock runs down.
- Every decision about timeouts and field position matters.

Play it here: https://2mindrillgame.org/
