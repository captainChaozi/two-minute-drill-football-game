# Clock management notes

Notes for [2 Minute Drill](https://2mindrillgame.org/), a free browser football strategy game built on the last two minutes of real NFL games.

## Two costs per snap
1. **Getting ready** – on a running clock, setup time is spent before the snap.
2. **Running the play** – the action itself takes seconds.

If preparation uses all remaining time, the snap never happens. A legal snap can finish after the clock reaches zero, but you cannot start one at zero.

## What stops the clock in this game
- Incomplete pass
- An actual out-of-bounds finish
- Timeout
- Completed spike

A first down does **not** stop the clock by itself.

## Reference timings (original drills)
| Action | Setup |
|---|---|
| Hurry-up ordinary play | 8 s |
| Huddle | 22 s |
| Hurry-up field goal | 12 s setup + 5 s kick |
| Spike | 3 s to prepare |

Historical endings use sampled setup estimates instead of fixed numbers.
